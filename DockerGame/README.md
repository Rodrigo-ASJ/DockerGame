# DockerGame

SPA gamificada para aprender Docker y Kubernetes. Este paquete contiene la aplicación web.

## Requisitos

- Node.js 24+
- pnpm 11+

## Comandos

```bash
pnpm install
pnpm dev
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```
